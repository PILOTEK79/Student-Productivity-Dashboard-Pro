**# 🎓 Student Productivity Dashboard Pro**

A modern student productivity platform designed to help students manage tasks, exams, goals, study sessions, and academic performance from a single dashboard.

## Features

- 📋 Advanced Task Manager
- 📚 Exam Tracker
- 🎯 Goal Management
- ⏱ Pomodoro Study Timer
- 🎓 GPA Calculator
- 📈 Analytics Dashboard
- 🌙 Dark Mode
- 🤖 AI Study Assistant (Planned)

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
- Local Storage
